# dcit-318-assignment3-22050269

A collection of C# console applications developed to practice **Object-Oriented Programming (OOP), Generics, Collections, Records, Interfaces, Exception Handling, and File Operations**.

## Projects

### 1. Finance Management System

A simple finance system that manages transactions and accounts.

### 2. Healthcare Management System
A healthcare system for managing patients and their prescriptions

### 3. Warehouse Inventory Management System
An inventory system that manages grocery and electronic products.

### 4. Student Grading System
A file-based grading system that reads student records, assigns grades, and generates a report.
